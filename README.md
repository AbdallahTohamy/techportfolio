# Abdallah El Tohamy — Portfolio

Next.js (App Router) site with a small backend for the contact form.

```bash
npm install
npm run dev      # http://localhost:3000
npm run build && npm start
```

## Editing content

All copy lives in [`data/content.js`](data/content.js): profile, stats, the Shanda pipeline, projects
(galleries, then→now comparisons, links), skills, client reviews and rowing results. Project screenshots are in
`public/media/projects/`.

## Contact form email

`POST /api/contact` (in `app/api/contact/route.js`) validates the message, filters bots with a honeypot and
rate limits per IP. It then sends two emails through Gmail SMTP (templates in `lib/emailTemplates.js`):

1. A notification to `CONTACT_NOTIFY_EMAIL` with the request, where Reply goes straight to the visitor.
2. A confirmation to the visitor saying you will get back to them within a few days.

Set these in `.env.local` locally and in **Netlify > Site configuration > Environment variables**:

| Variable | Purpose |
| --- | --- |
| `GMAIL_ADDRESS` | Gmail account that sends the emails |
| `GMAIL_APP_PASSWORD` | A Google App Password for that account (Google Account > Security > App passwords) |
| `CONTACT_NOTIFY_EMAIL` | Where new requests are announced |
| `NEXT_PUBLIC_GA_ID` | Google Analytics 4 ID (optional) |
| `NEXT_PUBLIC_SITE_URL` | Public URL for canonical links and the sitemap, if not the Netlify URL (optional) |
| `NEXT_PUBLIC_GOOGLE_SITE_VERIFICATION` | Google Search Console verification token (optional) |

Without the Gmail variables the form still works but asks visitors to email directly.

## SEO

Metadata, Open Graph/Twitter cards, `robots.txt`, `sitemap.xml`, a web manifest and schema.org JSON-LD
(Person, WebSite, ProfilePage, projects) are generated by Next.js from `lib/site.js` and `data/content.js`.

## Deploy

Netlify builds it automatically from `netlify.toml` (Next.js runtime, Node 22).
